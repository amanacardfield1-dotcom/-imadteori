# أكاديمية عماد للتيوري السويدي

موقع تدريبي **مجاني** لمساعدة متدربي عماد (@im10471 على تيك توك) على مراجعة أسئلة اختبار
التيوري (النظري) لرخصة القيادة في السويد بعد حضور بثوثه المباشرة.

> ملاحظة حقوق نشر: أسئلة هذا الموقع أصلية، مكتوبة استنادًا لقواعد المرور الرسمية المنشورة
> في السويد، وليست منسوخة من أي موقع أو مصدر آخر (البنك الحقيقي لأسئلة Trafikverket سرّي وغير
> منشور للعامة).

## البنية

```
imad-teori-academy/
  backend/     # Node.js + Express + JSON file storage (auth, quizzes, progress)
  frontend/    # React + Vite (RTL Arabic UI)
```

## التشغيل محليًا (VS Code)

### 1) الخادم (Backend)

```bash
cd backend
npm install
cp .env.example .env   # عدّل JWT_SECRET، وضبط ADMIN_EMAIL / ADMIN_PASSWORD لحساب صاحب المنصة
npm run dev
```

يعمل الخادم افتراضيًا على `http://localhost:4000`. عند أول تشغيل، يُنشئ الخادم تلقائيًا حساب
صاحب المنصة (عماد) بالبريد وكلمة المرور المحددين في `ADMIN_EMAIL` / `ADMIN_PASSWORD`.

## نظام موافقة التسجيل

كل متدرب جديد يسجّل يبقى بحالة "بانتظار الموافقة" ولا يستطيع الوصول للاختبارات إلا بعد أن
يوافق عليه عماد شخصيًا من صفحة **لوحة الإدارة** (`/admin`) الظاهرة فقط لحسابه. هذا مطبّق على
مستوى الخادم (`backend/src/middleware/auth.js` → `requireApproved`) وليس فقط في الواجهة، لذا
لا يمكن الالتفاف عليه من المتصفح.

### 2) الواجهة (Frontend)

```bash
cd frontend
npm install
npm run dev
```

تفتح الواجهة افتراضيًا على `http://localhost:5173`، وتتصل تلقائيًا بالخادم عبر متغير
`VITE_API_URL` الموجود في `frontend/.env`.

## تحديث معلومات المدرب

عدّل الملف [`frontend/src/trainer.js`](frontend/src/trainer.js):
- استبدل `displayName` بالاسم الحقيقي الكامل.
- ضع صورة المدرب داخل `frontend/public/` (مثلاً `trainer.jpg`) وحدّث `photo` إلى `/trainer.jpg`.

## إضافة/تعديل أسئلة الاختبارات

كل الأسئلة موجودة في ملف واحد سهل التعديل: [`backend/data/questions.js`](backend/data/questions.js).
كل اختبار عبارة عن كائن بداخله مصفوفة أسئلة، وكل سؤال يحتوي:
- `text`: نص السؤال
- `options`: قائمة الخيارات
- `correctIndex`: رقم الخيار الصحيح (يبدأ من 0)
- `explanation`: شرح مبسط يظهر بعد الإجابة

يمكن لعماد إرسال أسئلته الخاصة من بثوثه المباشرة لاحقًا وإضافتها بنفس الشكل.

يحتوي الموقع حاليًا على **20 اختبارًا أصليًا (200 سؤال)** تغطي: إشارات المرور والأولوية، السرعة
والمسافة الآمنة، السلامة والبيئة، التجاوز، القيادة الليلية، الشتاء والثلج، الوقوف، مركبات
الطوارئ، الدراجات والمشاة، الطرق السريعة، حمولة المركبة والمقطورة، صيانة المركبة، التأمين
والوثائق، الأنفاق والجسور، مناطق المدارس، الوعي بالمخاطر، تكنولوجيا السيارة، الطرق الريفية،
الحوادث والإسعافات الأولية، ومراجعة شاملة نهائية.

## صفحة إشارات المرور المرجعية

صفحة `/traffic-signs` ([frontend/src/pages/TrafficSigns.jsx](frontend/src/pages/TrafficSigns.jsx))
مرجع سريع لفئات إشارات المرور السويدية (تحذير، منع، إلزام، أولوية، إعلامية، علامات أرضية) مع
أيقونات SVG أصلية توضح شكل ولون كل فئة. البيانات في
[frontend/src/signsData.js](frontend/src/signsData.js) قابلة للتوسيع بسهولة.

## النشر المجاني (Hosting)

- **الواجهة (Frontend)**: يُنشر مجانًا على [Vercel](https://vercel.com) أو [Netlify](https://netlify.com) — اربط المجلد `frontend` مباشرة بحساب GitHub.
- **الخادم (Backend)**: يُنشر مجانًا (بحدود الخطة المجانية) على [Render](https://render.com) — اربط المجلد `backend`، وأضف متغير البيئة `JWT_SECRET`.
- بعد النشر، حدّث `VITE_API_URL` في إعدادات Vercel/Netyfy ليشير إلى رابط الخادم المنشور بدل `localhost`.

## قاعدة البيانات

يستخدم المشروع حاليًا ملف `backend/db.json` كقاعدة بيانات بسيطة (كافية لعدد متوسط من
المتدربين). عند الحاجة لعدد أكبر من المستخدمين مستقبلًا، يمكن استبداله بقاعدة بيانات حقيقية
(مثل PostgreSQL) دون تغيير باقي الكود كثيرًا لأن كل الوصول لقاعدة البيانات معزول في
`backend/src/db.js`.
