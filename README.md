# أكاديمية عماد للتيوري السويدي

موقع تدريبي **مجاني** لمساعدة متدربي عماد (@im10471 على تيك توك) على مراجعة أسئلة اختبار
التيوري (النظري) لرخصة القيادة في السويد بعد حضور بثوثه المباشرة.

**🔴 الموقع مباشر على: https://imadteori.web.app**

> ملاحظة حقوق نشر: أسئلة هذا الموقع أصلية، مكتوبة استنادًا لقواعد المرور الرسمية المنشورة
> في السويد، وليست منسوخة من أي موقع أو مصدر آخر (البنك الحقيقي لأسئلة Trafikverket سرّي وغير
> منشور للعامة).

## البنية

الموقع عبارة عن **واجهة React ثابتة فقط** (لا يوجد خادم Node منفصل)، تعمل مباشرة مع
[Firebase](https://firebase.google.com) (خطة Spark المجانية، بدون بطاقة ائتمانية):

- **Firebase Hosting** — استضافة الواجهة الثابتة.
- **Firebase Authentication** (Email/Password) — تسجيل الدخول والحسابات.
- **Cloud Firestore** — تخزين حسابات المتدربين، حالتهم (بانتظار/مفعّل)، بنك الأسئلة، ونتائج
  الاختبارات.
- **Firestore Security Rules** ([`firestore.rules`](firestore.rules)) — تطبّق نظام موافقة
  التسجيل والصلاحيات على مستوى قاعدة البيانات نفسها، فلا يمكن الالتفاف عليها من المتصفح.

```
imad-teori-academy/
  frontend/    # React + Vite (RTL Arabic UI) — كل الموقع الفعلي المنشور
  backend/     # غير مستخدم في النشر الحالي؛ سكريبتات صيانة فقط (انظر أدناه)
  firestore.rules, firebase.json  # إعدادات Firebase
```

## نظام موافقة التسجيل

كل متدرب جديد يسجّل يبقى بحالة "بانتظار الموافقة" ولا يستطيع قراءة الاختبارات إلا بعد أن
يوافق عليه عماد شخصيًا من صفحة **لوحة الإدارة** (`/admin`) الظاهرة فقط لحسابه. هذا مطبّق داخل
[`firestore.rules`](firestore.rules) نفسها (وليس فقط بإخفاء الروابط في الواجهة)، بحيث حتى لو
حاول أحدهم الوصول المباشر لقاعدة البيانات فلن يتمكن من قراءة الاختبارات قبل الموافقة عليه.

## التشغيل محليًا (VS Code)

```bash
cd frontend
npm install
npm run dev
```

تفتح الواجهة على `http://localhost:5173` وتتصل مباشرة بنفس مشروع Firebase الحقيقي (`imadteori`)
عبر الإعدادات الموجودة في [`frontend/src/firebase.js`](frontend/src/firebase.js).

## تحديث معلومات المدرب

عدّل الملف [`frontend/src/trainer.js`](frontend/src/trainer.js):
- استبدل `displayName` بالاسم الحقيقي الكامل.
- ضع صورة المدرب داخل `frontend/public/` (مثلاً `trainer.jpg`) وحدّث `photo` إلى `/trainer.jpg`.

## إضافة/تعديل أسئلة الاختبارات

بنك الأسئلة الآن مخزّن في مجموعة `tests` داخل Firestore (وليس ملفًا في الكود). لإضافة أو
تعديل أسئلة:

1. عدّل الاختبارات في [`backend/data/questions.js`](backend/data/questions.js) (لا يزال هو
   مصدر الحقيقة الأصلي بصيغة سهلة القراءة).
2. شغّل سكريبت الرفع لمزامنة Firestore مع الملف:
   ```bash
   cd backend
   node scripts/seedFirebase.js
   ```
   (يحتاج ملف `backend/.env` ببيانات مشروع Firebase — راجع `.env.example`.)

يحتوي الموقع حاليًا على **20 اختبارًا أصليًا (200 سؤال)** تغطي: إشارات المرور والأولوية، السرعة
والمسافة الآمنة، السلامة والبيئة، التجاوز، القيادة الليلية، الشتاء والثلج، الوقوف، مركبات
الطوارئ، الدراجات والمشاة، الطرق السريعة، حمولة المركبة والمقطورة، صيانة المركبة، التأمين
والوثائق، الأنفاق والجسور، مناطق المدارس، الوعي بالمخاطر، تكنولوجيا السيارة، الطرق الريفية،
الحوادث والإسعافات الأولية، ومراجعة شاملة نهائية.

## صفحة إشارات المرور المرجعية

صفحة `/traffic-signs` ([frontend/src/pages/TrafficSigns.jsx](frontend/src/pages/TrafficSigns.jsx))
مرجع سريع لفئات إشارات المرور السويدية (تحذير، منع، إلزام، أولوية، إعلامية، علامات أرضية) مع
أيقونات SVG أصلية توضح شكل ولون كل فئة. البيانات في
[frontend/src/signsData.js](frontend/src/signsData.js) قابلة للتوسيع بسهولة.

## النشر (Deployment)

```bash
cd frontend
npm run build
cd ..
npx firebase-tools deploy --only hosting --project imadteori
```

لنشر تحديثات على قواعد الأمان بعد تعديل `firestore.rules`، استخدم:
```bash
node backend/scripts/deployRules.js
```
(نستخدم سكريبتًا مخصصًا بدل `firebase deploy --only firestore:rules` مباشرة، بسبب قيد صلاحيات
في حساب الخدمة الحالي مع أمر التحقق التلقائي من الـ CLI.)

## لماذا Firebase وليس Render/Vercel؟

جُرّب أولًا استضافة Backend منفصل (Node/Express) على Render، ثم Vercel، لكن كلا الخيارين
أصبحا يطلبان بطاقة ائتمانية للتحقق حتى في الخطط المجانية. أعيدت هندسة الموقع بالكامل ليعمل على
Firebase (Hosting + Auth + Firestore) لأنها المنصة الوحيدة التي تبقى **مجانية بالكامل بدون أي
بطاقة ائتمانية** لهذا الحجم من الاستخدام.
